# Hi, I'm Morante 👋

I work on **AI and data**, designing solutions and keeping an eye on what's next in AI.

I hold a **PhD in robotics** (Universidad Carlos III de Madrid, 2016) on how robots can learn actions
from human demonstrations, focusing on the *goal* of the action rather than copying the movement.
These days I'm back to building robots for fun.
